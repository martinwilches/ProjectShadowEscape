# PROJECT: SHADOW ESCAPE

## 1. General Information

- Name: Project Shadow Escape
- Genre: 2D Top-Down Survival
- Platform: Windows PC
- Engine: Godot 4.x
- Programming Language: GDScript
- Perspective: Top-Down
- Target Resolution: 1280x720
- Players: Single Player

## 2. Game Concept

The player wakes up in an abandoned forest.
The objective is to collect resources, avoid enemies
and escape before the timer reaches zero.

## 3. Core Gameplay Loop

1. Explore the environment.
2. Collect resources.
3. Avoid or defeat enemies.
4. Find the exit.
5. Complete the level.
6. Unlock the next challenge.

## 4. Main Mechanics

- Player movement

- Health system
